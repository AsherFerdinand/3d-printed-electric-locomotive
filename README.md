## 📌 Project Overview

This project involved the collaborative development of an **electrically driven model locomotive**, combining mechanical design, CAD modelling, additive manufacturing, electrical integration, and physical prototyping.

The project was carried out as a group engineering project, with responsibilities distributed across different technical work packages.

As the **project leader**, I coordinated the overall development process and contributed directly to the mechanical design, focusing primarily on the locomotive's housing, chassis, and coupling. I was also responsible for preparing 3D-printable components using **Ultimaker Cura**, connecting the CAD design process with physical manufacturing.

The locomotive was designed in **CATIA V5**, with selected components manufactured using FDM 3D printing. The development process included requirements analysis, conceptual design, component modelling, prototype iterations, assembly, and evaluation of the finished system.

### 🎯 Project Objectives

- 📋 Translate project requirements into a functional locomotive concept.
- 📐 Design mechanical components and assemblies in CATIA V5.
- 🧩 Develop the housing, chassis, and coupling.
- ⚙️ Integrate the gearbox, wheels, electric motor, and battery system.
- 🖨️ Prepare CAD components for additive manufacturing using Ultimaker Cura.
- 🔧 Assemble and refine the physical prototype.
- 🧪 Investigate curve-running behaviour and tipping stability.
- ♻️ Consider manufacturing costs, component lifetime, and recycling.
